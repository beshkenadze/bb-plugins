## Find a project fast

A dropdown at the top of the sidebar lists all your projects alphabetically.
Type a few letters to narrow the list, then pick a project with the mouse or
the keyboard.

## Land in its first thread

Choosing a project opens the top row of that project's group in the sidebar:
running threads first, then the latest activity. Pinned threads open only when
the project has nothing else, and the sidebar scrolls to the project's group. A
project without threads opens New thread with the project already selected. On phones the list opens as a sheet and the
sidebar closes after you choose.

## Requirements and data

Requires BB 0.46+ and Plugin SDK 0.6.49+. The switcher reads BB's live
sidebar data in the app. It stores nothing, runs no background work, and keeps
your existing sidebar thread list.
