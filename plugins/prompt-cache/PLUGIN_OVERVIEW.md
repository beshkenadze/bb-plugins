A badge in the thread header shows how much of the last prompt the cache served and how long until the cache expires; click it for the read / written / new split, where the lifetime comes from, what the next message costs with and without the cache at API prices, and how many recent turns sent the whole context again. When the cache is about to lapse, a banner above the composer asks you to reply, and once it lapsed on a large context it offers to compact the thread. It works for Claude Code, Codex and Pi threads, and it only reads the usage they report to bb: nothing leaves your machine.
