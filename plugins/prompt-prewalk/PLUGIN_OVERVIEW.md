Press the pre-walk button in the composer, and a model rewrites your draft into a clearer, more actionable prompt that you can edit and send as usual. You choose that model in the plugin settings with bb's own provider and model picker, independent of the thread's model. The rewrite replaces the draft only if you did not edit it meanwhile, and one click restores the original until you edit the result. The model runs as a short-lived hidden thread in an empty scratch directory, never in your checkout. Nothing leaves your machine except the call to the bb provider you chose.
